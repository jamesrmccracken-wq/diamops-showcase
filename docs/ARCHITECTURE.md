# DiamOps Architecture

## Public Showcase Scope

The public showcase describes the learner-facing product loop:

1. Select or receive a realistic IT ticket.
2. Review evidence and simulated system context.
3. Identify root cause and choose a next action.
4. Write structured incident notes.
5. Receive scoring and feedback.
6. Export proof of work for a portfolio conversation.

## Private Core Scope

The private core contains:

- admin control center
- learner management
- authentication
- persistence adapters
- pilot feedback systems
- validation dashboards
- deployment configuration
- AI-assisted guidance
- internal product intelligence

## Design Principles

- Make practical skill visible.
- Keep learner flow calm and structured.
- Separate demo-safe public material from operational internals.
- Use fake data in all public examples.
